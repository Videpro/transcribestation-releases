# TranscribeStation releases

Deze publieke repository bevat uitsluitend officiële releaseartefacten van TranscribeStation.

Een klantrelease verschijnt pas nadat de installer met Apple Developer ID is ondertekend en genotariseerd, de checksums en SBOM zijn gemaakt, en de cryptografisch ondertekende juridische AI-stemvrijgave geldig is. Broncode, private sleutels en interne juridische documenten worden hier niet gepubliceerd.

Gebruik uitsluitend downloads onder **Releases**.
